# Hangarin

Hangarin is a Django-based Task Manager web application designed to help users organize and manage their tasks in one place.

## Project Description

Hangarin allows users to create, view, update, and delete tasks. Each task can have a priority, category, deadline, status, subtasks, and notes. The project also includes user authentication and Google login using Django Allauth.

The project was developed using Django and Bootstrap and follows a simple dashboard-style interface.

## Features

- User registration and login
- Google login
- Dashboard with task statistics
- Create tasks
- View task list
- Update tasks
- Delete tasks
- Search tasks
- Sort tasks
- Task pagination
- Task priorities
- Task categories
- Task deadlines
- Task status
- Subtasks
- Notes
- Django administration panel
- Bootstrap-based interface
- Responsive layout
